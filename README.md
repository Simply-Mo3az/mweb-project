# MWEB — Digital Engineering & Professional Websites

A high-performance landing page for **MWEB**, an elite web development studio crafting high-velocity, zero-bloat web applications and digital flagships.

Designed following the visual identity from the reference image (`assets/mweb.png`): pitch black (`#000000`), signature phosphor terminal green (`#61C37D`), and pixel-crafted typography.

---

## 🚀 Architecture & Core Features

- **Bilingual Arabic & English Support**: Dedicated language switcher button (`العربية / EN`) in the navigation bar. Instant, reactive switching with full RTL layout support (`dir="rtl"`), specialized Cairo and IBM Plex Sans Arabic typography, and complete professional localization.
- **Permanent Pitch-Black Theme**: Strict pitch black (`#000000`) canvas with obsidian card surfaces and phosphor terminal green (`#61C37D`) accents.
- **Zero Fabricated Content**: Authentic engineering capabilities, concrete architectural standards, transparent scope calculator, and direct consultation brief.
- **Interactive Workbench Terminal**: Live telemetry switcher (`Benchmark.sh`, `Architecture.tsx`, `Security.log`) demonstrating sub-200ms latency targets and zero layout shift.
- **The MWEB Discipline (Comparison Ledger)**: Contrast between typical bloated template agencies and MWEB's hand-crafted engineering standard.
- **Engineering Capabilities Matrix**: SaaS web applications, 3D brand flagships, headless commerce, and speed/Core Web Vitals refactoring.
- **Interactive Scope Estimator**: Real-time project cost and timeline calculator that allows visitors to customize project parameters and transfer the configuration directly into the inquiry brief.
- **Architectural Standards Bar**: 100% custom code commitment, <200ms target response, direct client repository ownership, and WCAG 2.2 AA accessibility.
- **Technical Inquiries & FAQ**: Keyboard-accessible accordions answering IP ownership, timeline, team structure, and maintenance.
- **Direct Dispatch Brief**: Client-side validated console form with strict NDA notice and toast dispatch notification.
